

\# Stock Price Prediction Using Machine Learning



\## Project Overview

This project is a Python-based web application for exploring stock market data and forecasting stock prices.



\## Features

\- Retrieve stock market data using Yahoo Finance.

\- Display stock data through interactive charts.

\- Forecast stock prices using an AutoReg time-series model.

\- Provide login and registration functionality in the original application.



\## Technologies Used

\- Python

\- Streamlit

\- Pandas

\- Yahoo Finance (`yfinance`)

\- Plotly

\- Statsmodels



\## Installation

Install the required libraries:



```bash

pip install -r requirements.txt

```



\## Run the Application

```bash

streamlit run four.py

```



\## Security Note

User authentication files and user data should be reviewed and secured before deployment.
